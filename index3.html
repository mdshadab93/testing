Class Monitoring Duty Chart

Every faculty (except Dr.) has 2 duties in the week, each in a free lecture with no lecture just before or after it. Duties run Monday to Friday; each lecture has 2 or more monitors.

Add / remove faculty on the duty chart

Untick to remove a faculty from the chart (their duties are deleted). Tick to add one (including Dr.); they get 2 duties automatically. You can also use × and "+ add" inside the chart for single lectures.

Users

Tick or untick a feature (tab) to give it to or take it away from a user. Changes are saved to Supabase at once and apply the next time that user signs in. Use All / None for quick changes. The admin always has every feature.

Share this page

Press Download page for sharing to get a copy of this page that already contains the current timetable data and duty chart. Upload that file (renamed to index.html) to GitHub to publish it on Vercel. Logins are checked online in Supabase, so they do not need to be shared.

Please note: this is a simple access gate. Anyone who holds the file can read its code, so do not rely on it to protect sensitive data.
